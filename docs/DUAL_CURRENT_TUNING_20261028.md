# 双轮独立电流环调参

六相电流图已删除，六相采样、CSV与原始日志保留。
M1、M2分别设置电流 Kp/Ki；每轮内部 d/q 两环仍共用该轮增益。
电流模式选择单轮，另一轮物理PWM/EN关闭。普通调参持续运行，正常结束后应用参数。
两轮分别提供 Iq目标/实际、Id目标/实际曲线以及Ud/Uq、Park有效、overrun诊断。

协议仍为32字节配置：原Kp/Ki字段用于M1，字节20/22的两个uint16用于M2，字节27位7标识独立配置。旧配置未设置该位时，两轮沿用共享增益。
新上位机拒绝向旧固件应用独立参数，避免产生已经分别生效的错觉。
遥测payload=200字节，加XOR共201字节；原M2 trace位于126，新增M1 trace位于166，CRC位于198。每个trace来自本轮实际Park/PI输出，不能用指令代替反馈。
曲线为约200Hz抽样，不证明20kHz电流环带宽或捕获全部尖峰。

新版位流尚未下载、尚未上板验收。M2电流零点漂移和标定失败尚未解决，不能把新增调试工具视为问题已修复。
下载前断电机12V并保留逻辑供电；下载会丢失姿态/电流校零和电角标定。

## 固定车辆方向

删除姿态与车轮方向选择区，Config不再包含m1_reverse/m2_reverse。配置字节3恒为3，其他位保留零，FPGA拒绝旧方向位。
直立/速度模式M1取共同Iq的负值、M2取原值；电流模式两轮均使用原始Iq，正Iq对应M1向前、M2向后。电角零位与编码器方向学习不变。

## 工作区与原限时版本（已由下述持续版本替代）

电流模式配置必须100..5000ms，默认1000ms；FPGA拒绝电流模式零时长，直立/速度模式仍发0持续运行。页面电流时长只在电流模式显示。曲线和对应Kp/Ki移动到右侧首屏，操作条固定顶部；M1/M2/双轮视图切换不发送硬件命令，测试轴以左侧选择和操作条提示为准。左右区域独立滚动，历史与校准步骤默认折叠。

## 2026-10-29 电流模式软限速与 Uq

新增 current_speed_limit_rpm，默认100rpm，范围10..1000rpm，模式1配置字节30/31复用为uint16 0.1rpm单位限速；模式2仍为原速度PI增益，两者互不覆盖。FPGA拒绝电流模式缺少有效限速。
仅在运行电流模式时，对两轮分别按绝对轮速减小原Iq：低于上限75%不变，75%至100%线性减小，到上限归零，降速后恢复。保持电流正负号，不反向制动，不作用于标定、直立/速度模式。使用现有50Hz编码器轮速，因此不是严格机械转速硬约束，可能因测量和惯性短时超速；原100..5000ms运行时限仍保留。
每轮Id/Iq图下增加Uq曲线（归一化指令，非伏特），灰线为正负限幅：运行0.75、标定0.25。字段取实际PI反馈，不以请求Iq代替实际Iq。显示限速介入、轮速与Uq是否贴近限幅。
遥测byte164 bit1声明限速能力，bit2/3为两轮限速状态。旧固件不会被当作支持限速；新主机拒绝旧固件的电流模式参数。
本改动尚未上板验证。命令新鲜度比较从输出组合路径移到等价的提前预测寄存结果，超时撤销arm的时钟边界不变，新增逐时钟等价测试。

## 2026-10-29 持续电流版本

电流模式与直立/速度模式均持续运行，直到用户结束、Stop、通信超时或硬件故障。删除运行时长输入、Config.duration_ms 和 FPGA 运行到期计时器；协议字节24/25保留且必须为0。上面描述的100..5000ms政策已废止。

遥测byte164 bit4声明持续电流能力；上位机要求电流模式同时具备限速与持续能力，防止旧固件误执行。原2秒试转按钮和有限时的参数对照测试入口已删除，历史测试记录仍可只读查看。M1/M2独立PI、Id/Iq/Uq曲线和可调软限速保留。

限速通过减小Iq工作，不反向制动，不能保证严格不超速，也不能避免持续通电发热。正常结束保留校准，Stop用于急停。此版本已完成离线验证与构建，尚未下载或进行电机实测。
