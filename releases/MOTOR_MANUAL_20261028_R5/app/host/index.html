手动调参步骤 · R5

首次须下载R5固件并校准。之后：结束运行 / 保留校准 → 改参数 → 应用并确认 → 开始持续调参。所有模式需主动结束；Stop / Esc用于异常急停。

电机验收后：断电下载驱动版 → 使能关闭下通 12V → 电流校零 → 明确选择右轮 M1 或左轮 M2，可先标任一路。按钮仅启动指定电机；新版普通清故障保留成功的电角标定；点击已完成的一路会重新标定该路。复位/下载后仍需标定，失败不自动重试。

电流模式直接给 Iq；直立模式 PD 给 Iq；速度模式 PI 给俯仰修正，再经 PD 给 Iq。心跳超时和驱动 nFAULT 均停机；所有模式均持续运行，需手动结束。
