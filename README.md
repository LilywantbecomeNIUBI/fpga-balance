## 1. 打开就能做什么

解压或克隆到英文短路径，例如`E:\fpga-balance`。安装Python3.10+，然后双击：

|---|---|---|
| `01_demo.cmd` | 模拟上位机，浏览器自动打开 | 否 |

## 2. 当前硬件与成功配置

ACG720/GW5AT-138B，Carrier_Hall_RevB，POWER_DRV8323HR六PWM，4015电机11极对，12V，AD7606、MT6701、ICM-42688-P。配置清单：[hardware/active_profile.json](hardware/active_profile.json)，物理引脚：[carrier_gpio.csv](hardware/reference/carrier_gpio.csv)。

| 项目 | M1 | M2 |
|---|---|---|
| PWM/EN/nFAULT接口 | 1 | 2 |
| 编码器接口 | 1 | 2 |
| C相电流OUT | CH1 | CH3 |
| B相电流OUT | CH2 | CH4 |
| 软件电流符号 | CH1/2取反 | CH3取反，CH4不取反 |
| C/B增益Q16 | 217082/220767 | 217082/220767，沿用比较值，未独立校准 |

真实电流`CURRENT_REVERSE=7`、`CURRENT_CB_MASK=3`、无通道交换、PWM为ABC；软件过流停机关闭、标定Id0.25A、运行Iq限幅±1.0A均为依赖传感器增益的标称值。沿用20µs/5µs暂定补偿及成功基准的命令斜坡64、速度参数512ticks（检查关闭）。

霍尔IP+/IP−方向与上述软件符号必须**一起**记录。不要仅凭电机线颜色、模块型号或旧照片再统一翻符号。M2的CH4霍尔可能与其他型号不同，增益仍待独立标定。A相由B/C重建，三相和为0不是独立接线证据。

电流极性、轮子转矩方向、编码器前进速度方向是三件事。当前成功证据支持电流极性；机身IMU安装方向、左右轮恢复力矩和前进轮速仍需实物确认。所有人工确认框默认关闭。

## 3. 控制与上位机

根源码版 FPGA 顶层为 `balance/src/balance_top.v`，上位机为 `balance/host/server.py`；当前手动固定版使用 R4 `app/host/server.py`。

- **电流短测**：选M1/M2/双路，给限时Iq，默认0mA。未选轴Iq为0，不等于该轴硬断电；独立轴试验的历史成功不自动等于双轴集成通过。
- **直立PD**：1kHz姿态，PD输出两轮Iq，速度外环关闭。
- **直立+速度PI**：50Hz编码器速度PI输出俯仰修正±3°，总目标trim±5°，再由PD产生Iq。带退出清积分和条件抗饱和；不是把旧电机转速环串到直立控制里。

网页提供曲线、模式/PI/PD配置、完整回显、方向选项、门禁状态、JSON参数导入导出、CSV和原始串口记录。数据约200Hz，不能代表全部20kHz电流样本；本集成遥测没有两路同时完整Id/Iq/PI内部波形，精细带宽测量需另外增加相干采样和测试。

V2协议头`A5 B6 02 80`，921600/8N1，实际UART分频54。连接时先被动识别正确CRC，再发停止；旧FOC、IMU和V1集成固件不会收到控制帧。参数导入只改表单，验收确认位会复位，不自动发送或运行。详细字段见[PROTOCOL](balance/PROTOCOL.md)。

当前集成精简版停机保护：nFAULT、Stop、倾角、100ms主机心跳；页面失联请求停止。软件过流、编码器速度及时间关系不再停机。静止电流仅打印/记录Warning。仍保留参数确认、电流校零、电角标定、命令斜坡、单次解锁及正常限时结束。详见balance/PROTOCOL.md。

## 4. 正确调试顺序

详见[TUNING_GUIDE](docs/TUNING_GUIDE.md)。先模拟和离线测试，再12V关闭下载观察版，确认姿态、通道与方向。用户确认现场条件后才用驱动版重新校零、逐轴标定、小电流限时试验。电流环稳定后，在支撑下调直立PD；直立稳定后才加入速度PI。

当前运行Iq硬上限为±1A；该上限及1000rpm尚未实物验收。

## 5. 构建、交接与常见问题

Gowin默认`C:\Gowin\Gowin_V1.9.12.04_x64\IDE`，可设置`GOWIN_IDE`。厂商FOC Light加密IP不入源码包；`prepare_ip.py`从本机合法Gowin安装恢复并核对来源。构建生成的工程所有路径来自当前仓库，不引用旧仓库。test模型仅供仿真，绝不能放进综合工程代替真实IP。

每次构建看`balance/build/<profile>/result.json`：必须`success=true`且Setup/Hold违例均0。observe还要求综合网表16个电机输出接GND。构建脚本只构建、不下载；新编译不能沿用历史位流哈希。上板前12V关闭、逻辑供电开启，以SRAM方式手动选对应候选；本工程不提供自动刷写/自动启动。

- **无法识别固件**：板上可能仍是旧FOC固件；不能用新上位机“强行连接”来代替下载正确程序。
- **只有蓝牙COM口**：检查逻辑供电与数据USB；串口号不固定，按USB设备身份选择。
- **环境错乱**：只用本目录启动器，关闭旧上位机；不要把旧`.venv`、build或旧协议模块复制过来。
- **参数失效**：停止/清故障后按门禁重新应用参数、校零；新版保留已成功电角标定，复位/下载后重标；不要自动重发运动命令。
- **源码哈希变化**：代表文件已修改，先查看改动并重新测试，不要直接跳过校验。

给AI或队友时，发送本仓库ZIP并让其先读[AI_HANDOFF](AI_HANDOFF.md)。包不包含账号凭据、原仓库Git历史或历史实验固件。新仓库默认私有，队友需要仓库权限或直接接收ZIP。

2026-10-27独立标定入口：上位机提供“标定右轮 M1”和“标定左轮 M2”两个按钮，可任选顺序。需配套支持标志的新固件；旧的自动下一路命令已拒绝。新版普通清故障保留两路已成功的电角标定；电流/姿态校零仍失效。点击已完成的一路会仅重新标定该路，复位/下载清空两路标定。两路均完成后才允许双轮运行，故障不会自动恢复。
