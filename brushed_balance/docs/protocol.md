# 独立协议与控制单位

115200、8N1。命令和状态均为 48 字节，整数字段均小端。
CRC16-CCITT-FALSE：poly 0x1021、init 0xFFFF，覆盖前 46 字节，末尾 CRC 低字节在前。
与旧的 FOC、原有刷电机、Nano 网关协议不兼容；本上位机独占实际串口。

## 命令

| 字节 | 含义 |
| --- | --- |
| 0..1 | B6 6B |
| 2 | 版本 1 |
| 3 | STOP=0 / CLEAR=1 / CONFIG=2 / ZERO=3 / ARM=4 / TARGET=5 / HEARTBEAT=6 |
| 4 | 8位序号 |
| 5 | 必须为 0 |
| 6..45 | 40字节 payload |
| 46..47 | CRC |

STOP 可重复、绕过序号检查并锁存停车；其他命令序号须向前 1..127，支持 255→0。无效命令、坏 CRC 和重复序号不能续命。部分帧 20ms 超时。CLEAR、ZERO、ARM、HEARTBEAT 的 payload 全零；ARM 将各目标归零。清除故障不自动 ARM，保留已经完成的姿态零点；IMU 故障/复位会使姿态零点失效。

CONFIG 只在停机时接收，全部字段校验后原子应用，状态独立回报配置序号。下表偏移从 payload 0 开始：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u8 | 模式 0..4 |
| 1 | u8 | bit0/1左/右电机反向，bit2/3左/右编码器反向，bit4直立公共输出反向 |
| 2 | u8 | axis：观察0，单轮1左/2右，平衡3 |
| 3 | u8 | 融合 filter_shift，2..10 |
| 4 | u16 | PWM 上限，1..300‰ |
| 6 / 8 | u16 | 直立 Kp/Kd，Q8；单位 ‰/° 与 ‰/(°/s) |
| 10 / 12 | u16 | 单轮速度 PI 的 Kp/Ki，Q8；误差单位计数/10ms，Ki每10ms累加 |
| 14 | u16 | 速度外环 Kp，Q16 °/rpm |
| 16 | u16 | 速度外环 Ki / 50，Q16 °/rpm/每20ms；页面单位为 °/(rpm·s) |
| 18 | i16 | 直立微调，0.01° |
| 20 / 22 | u16 | 允许启动角、倾倒停机角，0.01° |
| 24 | u16 | 速度外环输出倾角上限，0.01°，最大6° |
| 26 | u16 | 单轮测试时长ms，100..5000；观察/平衡必须0 |
| 28..39 | 零 | 保留 |

TARGET payload：偏移0/2为左右 i16 目标；PWM模式单位‰，单轮速度模式单位计数/10ms。未选轮必须0。偏移4为整车速度目标 i16 Q8 rpm，仅模式4使用，最大±120rpm；剩余字节全零。模式3只允许零目标。

## 状态

| 字节 | 类型 | 含义 |
| --- | --- | --- |
| 0..2 | 常量 | CB BC 01 |
| 3 | u8 | 最后接受的非STOP命令序号 |
| 4 | u8 | bit0 armed、1姿态已校零、2正在校零、3配置有效、4 IMU健康、6驱动版能力、7 M2-23～30集中引脚方案 |
| 5 | u8 | 模式 |
| 6..7 | u16 | faults |
| 8 / 10 | u16 | 左/右输出轴 CPR |
| 12 / 14 | i16 | 俯仰角0.01°、角速度0.01°/s（饱和显示） |
| 16 / 20 | i32 | 左/右位置，模2^32回绕 |
| 24 / 26 | i16 | 左/右10ms计数（饱和显示） |
| 28 / 30 | i16 | 左/右实际选择后的PWM指令‰；不含唤醒期的11状态 |
| 32 / 34 | u16 | 左/右非法跳变累计值低16位 |
| 36 | i16 | 速度外环倾角0.01° |
| 38 | u8 | 最后接受的CONFIG序号 |
| 39 | u8 | 停机原因：0初始/清错、1 STOP、2故障、3单轮到时 |
| 40 | u16 | IMU提交间隔µs |
| 42 | u16 | 策略拒绝+坏帧计数，模65536 |
| 44 | u16 | 遥测序号 |
| 46 | u16 | CRC |

bit7为1时，上位机解码为`carrier_m2_23_30`；为0时为`legacy_distributed`。M2上位机仍可读取旧状态，但拒绝旧引脚固件解锁，避免把软件版本识别误作新接线已完成。

faults：bit0上电/STOP锁存，1心跳超时，2 IMU或姿态过期，3倾倒，4非法AB跳变过多，5编码器计数速度越界，6有输出无编码器运动。运行中异常优先于同拍命令，不自动清锁存。

## 符号

姿态/角速度为有符号 Q16 度/度每秒。默认前倾为正；直立公共输出为 `Kp*(pitch-target)+Kd*rate`，再按公共与左右电机方向位映射。
外环以两轮正向 rpm 的平均值反馈，`error=target_rpm-feedback_rpm`，PI 输出目标倾角修正。两轮朝车辆前进方向的反馈必须统一为正。
正负方向由实物检查确认；源码中的符号定义不是对新车安装方向的验收结果。

## 只读IMU诊断帧

新增独立48字节`CB BD 01`帧，5Hz，与原`CB BC 01`控制状态帧交替发送，CRC规则相同。此帧不续命、不改变控制状态；旧固件没有它时上位机显示“等待诊断遥测”。

字节3=last_error，4=WHO_AM_I（应为0x47），5的bit0/1/2/3为ready/fault/stale/温度有效、bit4/5为同步后的SDA/SCL电平，6=配置I2C地址0x69，7保留0；8/12为原始样本序号/样本年龄u32；16/18为错误/无效计数u16；20/22为SCL/SDA低电平采样占比u16（‰）；24..35为ax/ay/az/gx/gy/gz有符号原始六轴；36/40为now_us/commit_us u32；44为诊断序号u16；46为CRC。低电平占比按1kHz采样、200ms窗口统计，用于卡低诊断，不能测量模拟波形质量。
